#  DigiTools — Supercharge Your Digital Workflow

 A modern, fully responsive digital tools marketplace built with React.js, Tailwind CSS, and DaisyUI — featuring a real-time cart system powered by React Toastify notifications.


# Technologies Used

| Technology | Version | Purpose |
|---|---|---|
| **React.js** | ^18.2.0 | Component-based UI framework |
| **Tailwind CSS** | ^3.3.3 | Utility-first styling |
| **DaisyUI** | ^3.9.4 | Pre-built UI components |
| **React Toastify** | ^9.1.3 | Toast notifications |
| **React Icons** | ^4.12.0 | Scalable icon library |
| **Vite** | ^4.4.9 | Lightning-fast build tool |
| **JavaScript ES6+** | — | Arrow functions, destructuring, spread |
| **JSON** | — | Static product data store |

  Compatible with **Node.js v16+** and **Vite 4**


# Key Features

# 1. Live Cart System with Toast Notifications
Add products to your cart with a single click. The navbar badge updates in real time, and React Toastify fires contextual alerts — success on add, error on remove, and a confirmation on checkout. Duplicate prevention is built in with an informational toast.

# 2. Seamless Product / Cart Tab Toggle
The main section features two centered pill-shaped toggle buttons. Clicking **Products** renders the full 3-column product grid; clicking **Cart (n)** switches to the cart view — showing items, a live-calculated total, and a "Proceed to Checkout" button that clears the cart.

# 3. Fully Responsive Design
Every section — Navbar, Banner, Stats, Product Grid, Steps, Pricing, CTA, and Footer — is built mobile-first. The layout adapts from a single column on mobile to 2–3 columns on tablet and desktop using Tailwind's responsive prefixes (`sm:`, `md:`, `lg:`).
